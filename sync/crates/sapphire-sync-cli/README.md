# sapphire-sync-cli

The command line of [sapphire-sync](https://github.com/sapphire-turtle/sapphire-sync)'s
two editions: its commands (`sync`, and sapphire-framework's `serve`, `status`, `service`,
`workspace`, `api-key`, `config`, …), which run the app server or call it, as a library.
Workgroups, devices and embedding are `sapphire-bridge`'s commands.

To install the command, see [`sapphire-sync-headless`](../../headless/README.md) (no GUI)
or the desktop app; both put `sapphire-sync` on PATH.
