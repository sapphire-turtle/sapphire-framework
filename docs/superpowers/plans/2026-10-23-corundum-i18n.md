# corundum-gui Translations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Strings in corundum-gui and sapphire-framework-gui looked up through Fluent, in English and Japanese, with a language setting that switches without a restart.

**Architecture:** An `i18n` module in corundum-gui keeps the registered `.ftl` resources and the installed bundles (chosen language + English) in the egui context, as `theme` does. Components call `tr!(ui, "id", …)` every frame; labels held across frames are message ids. sapphire-framework-gui registers its own resources and moves every screen string over; its `model.rs` returns `Message` values instead of English text.

**Tech Stack:** Rust, egui 0.36, fluent-bundle 0.16, fluent-langneg 0.14, unic-langid 0.9, sys-locale 0.3, jni 0.21 (Android).

**Spec:** `docs/superpowers/specs/2026-10-23-corundum-i18n-design.md`

## Global Constraints

- Dependencies (corundum-gui): `fluent-bundle = "0.16"`, `fluent-langneg = "0.14"`, `unic-langid = "0.9"`, `sys-locale = "0.3"`; Android only: `jni = "0.21"`, `ndk-context = "0.1"`. No regex crate.
- Bundles are `fluent_bundle::concurrent::FluentBundle`, `set_use_isolating(false)`, behind `Arc`.
- Lookup order: chosen language → `en` → the id itself. Misses and formatting errors logged once per id at `warn`.
- Keys: `corundum-…` in corundum-gui, `sapphire-…` in sapphire-framework-gui, shaped `<prefix>-<area>-<what>` (`sapphire-devices-rename`).
- Files: `crates/corundum-gui/locales/{en,ja}/corundum.ftl`, `crates/sapphire-framework-gui/locales/{en,ja}/sapphire.ftl`.
- `Language::default()` is `System`; `LanguageSettings` gets serde derives under corundum-gui's existing `serde` feature, `#[serde(default)]` on the struct.
- Not translated: backend/bridge text (errors, pause reasons, `EmbedNote`), names, paths, versions, ids, size units, `tracing` messages.
- Japanese glossary: workspace ワークスペース, workgroup ワークグループ, device デバイス, sync 同期, settings 設定, appearance 外観, language 言語, system システム, contrast コントラスト, accent アクセント, embedding 埋め込み, peer ピア, primary/secondary プライマリ/セカンダリ, model モデル. Sentences in です/ます; buttons as short verbs or nouns (「移動…」「削除」).
- CHANGELOGs are generated by release-plz from commit messages; mark the `Shell` label change as breaking with `feat(corundum-gui)!:`.
- Match the surrounding doc-comment style (full sentences, `[`links`]`).
- Run tests with `cargo test -p <crate>` from the worktree root `../sapphire-framework-wt-i18n`; its `target/` is on disk.

## Review Focus

- The system reports a regional tag the files do not have (`ja-JP`, `en-US`, `zh-Hant-TW`): `ja-JP` → ja, `en-US` → en, `zh-Hant-TW` → en — test in Task 1.
- `Language::Explicit` holding a garbage or removed tag (`"xx-!!"`, `""`): installs English, no panic — test in Task 1.
- A message whose argument is missing in one language: still shows the rest of the text, logs once — test in Task 1.
- `register` called every frame (an app registering in `update`): idempotent by name, no rebuild after the first — test in Task 1.
- A language switch with screens already built: labels held in structs (Shell destinations, the Settings page list) show the new language on the next frame, not the one they were built in — tests in Task 4 (`hover_text_follows_the_language`) and Task 6 (`settings_list_follows_the_language`).

**Interfaces:**
- Produces (in `corundum_gui::i18n`):
  - `struct LanguageSettings { pub language: Language }`, `enum Language { System, Explicit(String) }` — `Clone, PartialEq, Eq, Debug, Default`.
  - `#[derive(Clone, Copy)] struct Resources { pub name: &'static str, pub files: &'static [(&'static str, &'static str)] }`; `pub const CORUNDUM: Resources` (name `"corundum-gui"`).
  - `fn register(ctx: &egui::Context, resources: Resources)` — appended after earlier ones; a name already registered is ignored; rebuilds if installed.
  - `fn install(ctx: &egui::Context, settings: &LanguageSettings)`; `fn is_installed(ctx) -> bool`; `fn current(ctx) -> LanguageIdentifier` (`en` before install); `fn available(ctx) -> Vec<LanguageIdentifier>` (en first, then the rest sorted by tag).
  - `fn tr(ctx: &egui::Context, id: &str) -> String`; `fn tr_args(ctx: &egui::Context, id: &str, args: &[(&str, Arg)]) -> String`.
  - `fn name_of(ctx: &egui::Context, lang: &LanguageIdentifier) -> String` — `corundum-language-name` from that language's own resources (for the picker).
  - `trait AsContext { fn as_context(&self) -> &egui::Context }` for `egui::Ui` and `egui::Context`; `#[macro_export] macro_rules! tr` with forms `tr!(c, "id")` and `tr!(c, "id", name = expr, …)` (`expr: Into<Arg>`), expanding to `tr`/`tr_args` through `AsContext`.
  - `struct Message { pub id: &'static str, pub args: Vec<(&'static str, Arg)> }` with `new`, `arg`, `text(&self, ctx) -> String`; `enum Arg { Str(String), Num(f64) }` with `From` for `String`, `&str`, `f64`, `i32`, `i64`, `u32`, `u64`, `usize`.
  - `pub(crate) fn choose(requested: &[String], available: &[LanguageIdentifier]) -> LanguageIdentifier` — `negotiate_languages(Filtering, default en)`; unparsable tags skipped.
  - `i18n::check`: `fn parse_errors(r: &Resources) -> Vec<String>`; `fn key_difference(r: &Resources, a: &str, b: &str) -> Vec<String>` (keys in one and not the other, as `"ja lacks x"`); `fn unknown_ids(r: &Resources, lang: &str, src: &Path, prefix: &str, ignore: &[&str]) -> Vec<String>` — walks `src` for `.rs` files, collects every string literal matching `"<prefix>[a-z0-9-]+"`, reports those missing from `lang`'s file (with `file:line`).

`install` reads the system list through a `pub(crate) fn system_languages() -> Vec<String>` that returns `vec![]` in this task (Task 2 fills it). Stored state: the registered list under one `ctx.data` temp key; the installed bundles, the settings, the chosen id and a `Mutex<HashSet<String>>` of reported ids under another.
